Ajustar 3MF

Abre um projeto do Bambu Studio (sem fatiar), copia o prompt para a AI que preferires, cola a resposta e descarrega o -ajustado.3mf. O ficheiro nunca sai do browser; só sai o texto do prompt, que podes ler antes de copiar.

Experimentar com um projeto de exemplo

1. Projeto
Arrasta aqui o .3mf ou clica para escolher
2. Contexto
3. Prompt

Copia isto para o ChatGPT, Claude, Gemini ou um modelo local. Revê o texto: é tudo o que vai ser enviado.

4. Resposta

Cola aqui a resposta da AI (o JSON).

5. Alterações

Abre o ficheiro no Bambu Studio: as definições alteradas aparecem marcadas como editadas. Fatia lá.
